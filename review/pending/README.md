# Review gate

Ingestion writes proposed entries here. The build reads only `src/content/`.

Moving a file across this boundary requires an approved pull request. The
reviewer checks four things:

1. the link resolves to the correct case;
2. the citation, docket and date match the document;
3. the headnote contains no characterization of the judge and no prediction;
4. the appellate history is current as of the check date.

Record the approver and approval date in the entry before merging.
